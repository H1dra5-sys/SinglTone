# SinglTone

#Короткое описание
Лаба учит такому аспекту C# как наследование, что является неотъемлемой часть этого языка и помогает при решении задач, а так же паттерну проектирования Singltone.

#Программа
Сама программа представляет собой заранее подготовленный набор животных,  среди которых можно выбирать понравившихся и добавлять своих, так же у всех животных есть как одинаковый набор свойств, так и свойства подчёркивающие индивидуальность тех или иных животных(здесь наследование)
